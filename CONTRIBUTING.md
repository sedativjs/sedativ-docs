# Contributing

This project is open source, but it is not open to external code contributions.

The core project is maintained by the author. Pull requests for new features, refactoring, or other code changes are not accepted. This helps keep the project focused and maintain a consistent design and implementation.

# Extensions

The project's open-source license grants you the freedom to adapt it to your own needs.

You are welcome to:

- Build tools and applications on top of this project.
- Create libraries that integrate with this project.
- Publish plugins or extensions.
- Maintain forks with different goals or features.
- Share tutorials, examples, and documentation.

# Bugs and Security

If you believe you have found a bug or security vulnerability, please do not open a public issue with the details.

Instead, contact me privately at:

> walczakcezary@protonmail.com

Include enough information to reproduce the issue, such as affected versions, steps to reproduce, and any relevant details.

Thank you for your interest in this project.
